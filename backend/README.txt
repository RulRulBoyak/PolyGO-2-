1. Run `polygo.sql` in MySQL Workbench or MySQL Command Line to create the database and tables.
2. Copy this `polygo-api` folder into `C:\xampp\htdocs\`.
3. Edit `config.php` with your local MySQL password. The configured MySQL port is `3306`.
4. Start Apache and MySQL in XAMPP.
5. Test in a browser: http://localhost/polygo-api/listings.php
6. The Android emulator uses http://10.0.2.2/polygo-api/.
7. A physical phone must use your laptop Wi-Fi IP in NetworkApi.java.
